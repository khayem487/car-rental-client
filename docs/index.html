Car Rental Client Application

Client-facing web application for browsing vehicles, booking rentals, and managing profile/history.

JavaSpring BootThymeleafOracle DB
Source Code Portfolio

What it includes

  • User authentication and profile management
  • Vehicle catalog browsing with filters
  • Rental reservation workflow
  • Rental history tracking

Run locally

This project requires a Java backend + Oracle database, so GitHub Pages hosts an overview page only.

cd car-rental-client/car-rental-client

./mvnw clean package then ./mvnw spring-boot:run

App URL: http://localhost:8080
